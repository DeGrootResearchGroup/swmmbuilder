# SewerNetworkx
 Python module used take GeoJSON data of a sewer network and create subnetworks and .inp files for pyswmm

## SWMM template

`SubNetwork.write_pyswmm` fills the template shipped in the package,
`sewernetworkx/templates/template.inp` (`examples/pyswmm_template/template.inp` is a copy kept in
sync by a test). It uses SI units, `FLOW_UNITS LPS`, because the GIS lengths, inverts and sizes are
in metres. A custom template (`template_path=`) must use `CMS`, `LPS` or `MLD`, and may only
contain the `{nodes}`, `{outfalls}`, `{conduits}`, `{xsections}`, `{coordinates}` and `{vertices}`
placeholders; anything else (including US units or `{pumps}`, since pumps are not supported yet)
raises `ValueError`. Node `[COORDINATES]` and pipe `[VERTICES]` are written in the units of the GIS
geometry.

## Conduit geometry

Cross-sections come from the GIS `PipeShape` (sizes in mm, written in m): `R`/`Round` →
`CIRCULAR(Diameter)`, `REC` → `RECT_CLOSED(Height, Width)`, `EGG` → `EGG(Height)`, `ARC` →
`ARCH`, `ELH`/`ELV` → `HORIZ_ELLIPSE`/`VERT_ELLIPSE` (`Height, Width`). An unknown or missing
shape or size raises `ValueError` listing the pipe IDs, before anything is written.

A node's invert is the lowest invert of the subnetwork pipes connected to it, including the
`DropStructureInvert` of pipes entering it. Each conduit's inlet/outlet offset is its GIS pipe
invert minus the node invert (`LINK_OFFSETS DEPTH`), so conduits keep their GIS inverts; any that
slope uphill are reported with a warning. `height_correction={node: invert}` overrides a node's
invert, and the offsets are measured from it. The `inlet_offset`/`outlet_offset` arguments of
`write_pyswmm` are deprecated and ignored.

## Tests

```bash
pip install -e ".[test]"
pytest
```

The tests use a small synthetic network (`tests/data/fixture_network.geojson`, regenerated by
`tests/data/make_fixture.py`) that contains deliberate edge cases. Known bugs are encoded as strict
`xfail` tests that name their issue; a fix should turn its tests green and remove the marker.

On macOS, swmm-toolkit's wheel ships `libomp.dylib` and `libswmm-output.dylib` with invalid code
signatures, and `import pyswmm` is killed (exit 137). Re-sign them ad hoc:

```bash
codesign --force --sign - "$(python -c 'import swmm.toolkit, os; print(os.path.dirname(swmm.toolkit.__file__))')"/{libomp,libswmm-output}.dylib
```

## CI

`.github/workflows/ci.yml` runs ruff (`ruff check` and `ruff format --check`, rules in
`pyproject.toml`) and the test suite on Python 3.11–3.13. The `CI gate` job is the single check
to require in branch protection.
